# 1. 3단계의 목적
출력 / 지속력  
이미 안정된 공명을 밀어주는 힘, 즉 소리의 에너지 공급
흉곽·횡격막 기반 지지
공명이 안정되어 있으면 호흡 지지를 강하게 줘도 성대에 무리 없이 음량과 지속력 확보
호흡으로 발성을 지탱해 목이 힘을 쓰지 않도록 함
