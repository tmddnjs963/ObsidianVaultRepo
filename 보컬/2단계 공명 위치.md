# 1. 2단계의 목적
성대 보호 + 소리 조절  
고음이나 강한 소리에서도 성대를 안전하게 사용  
호흡 압력이나 발성 타입으로 인한 성대 과부하 방지  
공명 위치를 활용해 목을 직접 쓰지 않고 소리를 증폭

# 2. 공명의 정의
공명이란, 소리를 만들어내는 것이 아니라  
만들어진 소리가 성도를 통과하며  
증폭·변형·집중되는 모든 물리적·기능적 과정이다.


# 3. 공명 시스템의 4계층 구조
공명은 한 종류가 아니라 레이어로 구성된다  

    직접 공명
    기반 공명
    조절 공명
    엔진·컨트롤 시스템

모든 공명은 동시에 쓰이지 않는다  
공명은 의도보다 허용에 가깝다  
깨질 때는 공명보다 상위 시스템을 먼저 점검한다
모든 기술은 ON/OFF 가 아닌 사용율(%)을 조절하여 사용한다

# 4. 직접 공명 영역
    울리는 장소

## 4.1. 연구개 상승
    공명 스위치

<핵심>  
연구개 = 모든 공명의 천장

<느낌>
하품 직전  
“아—” 했을 때 입천장 뒤가 위로 들리는 느낌  
코를 막아도 소리 막히지 않음

<주의>  
너무 올림 → 소리 멀어짐 / 공기 많아짐  
안 올림 → 비성(소리가 비강으로 샘), 답답함(소리가 목 안에 갇힘)


## 4.2. 경구개 연구개 경계 공명
    미들 연결

이건 진짜 미들 보이스 핵심 중의 핵심🔥

<위치>  
단단한 입천장(경구개)과  
말랑한 입천장(연구개) 사이 경계

<역할>  
흉성 → 두성 넘어갈 때  
끊김 없이 다리 역할

<느낌>  
소리가 “입천장 뒤에서 미세하게 튕김”  
울림이 위로 가지만 머리로 날아가진 않음  

👉 이게 잘 되면  
미들 보이스 = 억지 X / 자연 O

## 4.3. 상부 구강 공명
    볼륨

2️⃣구강 공명 (입천장 + 옆 공간)
<핵심>
입천장 중앙 ❌
양 옆 공간 + 위쪽 돔 형태 ⭕
<느낌>
소리가 입 안에서 퍼져서 벽을 타고 도는 느낌
혀 위로 직접 때리지 않음
역할
소리의 볼륨·질감
말처럼 얇지 않게 만들어 줌

<주의>
입만 크게 벌림 ❌
혀로 소리 밀기 ❌
👉 구강 공명 = 소리의 몸통

## 4.4. 측면 구강 공명
    확장
    광대 안쪽 확장 느낌

## 4.5. 비강 공명
    해상도

<핵심>  
비강은 통로이지 출구가 아님  
소리는 입으로 나가고  
진동만 비강 쪽 벽을 스침

<느낌>  
코 안쪽이 미세하게 울림  
코 막아도 소리는 유지됨

<효과>  
선명도·집중력  
고음에서 소리 퍼짐 방지

<주의>  
비성과는 다름, 비음❌  
❌ 코로 내는 소리 아님  
❌ “맹~” 소리 아님

👉 비강 공명 = 해상도 담당

## 4.6. 인두 공간
    깊이

위치
인두 공간 (하품 직전)  
혀 뒤쪽 ~ 후두 앞 공간  
“크게 아—” 하기 전 순간

<느낌>  
목이 열린다 ❌  
뒤 공간이 넓어진다 ⭕

<역할>  
소리의 깊이·여유  
고음에서 조임 방지

<주의>  
공간만 만들고 힘 주면  
→ 무겁고 느린 소리  
👉 인두 = 깊이와 안정

## 4.7. 후두 안정 공명
    두께

⚠️ “인두 공간”이랑 비슷해 보이지만 의도와 역할이 다름

<핵심>  
하품 직전 후두가 살짝 내려간 상태  
소리의 두께·무게·안정감 담당

<효과>  
고음에서 소리 얇아지는 것 방지  
미들~고음에서 “속 빈 느낌” 제거

<주의>  
과하면 클래식/뮤지컬 톤  
‘내린다’가 아니라 ‘허용한다’ 느낌

👉 인두 공간 = 공간 확보  
👉 후두 하강 = 구조 안정화

## 4.8. 설근 이완
    공명 해제
    혀 뿌리 힘 빠질 때 하품 직전 느낌과 연결 설명 추가 추천

## 4.9. 마스크 공명
    관통력

<범위>  
코 옆  
윗입술  
광대 안쪽

<효과>  
고음에서 관통력 + 선명도  
작은 힘으로도 멀리 나가는 소리

<주의>  
비강 공명이랑 헷갈리기 쉬움  
코로 새면 실패  

👉 느낌은 “앞으로 모인다”  
👉 소리는 “위로 열린다”


## 4.10. 전방 포커스
    고음 조준

<핵심>  
왜 고음에서 중요?  
고음은 위로만 보내면  
→ 퍼짐 / 흔들림  
그래서 ➡️ 앞으로 모아줘야 함

<위치>  
윗입술 안쪽  
앞니 뒤  
입 밖으로 던지는 느낌 ❌  
앞에 걸어둔다 ⭕

<느낌>  
소리가 “앞에서 맺힘”  
작아 보여도 관통력 큼

<주의>  
턱 밀기  
입술 과사용


# 5. 기반 공명

## 5.1. 흉곽 공명
실제로 소리가 “울린다”기보단  
👉 전신이 공명을 받아주는 상태  
진성·미들에서 특히 중요

실제로 울리진 않지만 진성 기반 안정화용

<역할>  
진성·미들에서 몸 전체가 소리를 ‘받쳐주는 느낌’

<효과>  
성대 압박 감소  
감정 표현 시 흔들림 감소  

<주의>  
가슴에 울림을 만들려고 하지 말 것

👉 소리를 내는 게 아니라  
👉 소리를 맡긴다는 개념
