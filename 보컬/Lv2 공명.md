###### 직접 공명 영역
#### 1️⃣연구개 상승 (필수)

왜 “필수”인가
연구개는 공명의 스위치
안 올라가면
→ 공명은 전부 비강으로 새거나,
→ 소리가 목 안에 갇힘
<핵심>
하품 직전
“아—” 했을 때 입천장 뒤가 위로 들리는 느낌
코를 막아도 소리 막히지 않음
<주의>
너무 올림 → 소리 멀어짐 / 공기 많아짐
안 올림 → 비성, 답답함
👉 연구개 = 모든 공명의 천장

2️⃣구강 공명 (입천장 + 옆 공간)
<핵심>
입천장 중앙 ❌
양 옆 공간 + 위쪽 돔 형태 ⭕
<느낌>
소리가 입 안에서 퍼져서 벽을 타고 도는 느낌
혀 위로 직접 때리지 않음
역할
소리의 볼륨·질감
말처럼 얇지 않게 만들어 줌

<주의>
입만 크게 벌림 ❌
혀로 소리 밀기 ❌
👉 구강 공명 = 소리의 몸통


3️⃣비강 공명 (비성과는 다름, 비음❌)
<핵심>
비강은 통로이지 출구가 아님
소리는 입으로 나가고
진동만 비강 쪽 벽을 스침
느낌
코 안쪽이 미세하게 울림
코 막아도 소리는 유지됨
<효과>
선명도·집중력
고음에서 소리 퍼짐 방지

<주의>
❌ 코로 내는 소리 아님
❌ “맹~” 소리 아님

👉 비강 공명 = 해상도 담당

4️⃣인두 공간 (하품 직전) 
위치
혀 뒤쪽 ~ 후두 앞 공간
“크게 아—” 하기 전 순간
<느낌>
목이 열린다 ❌
뒤 공간이 넓어진다 ⭕
<역할>
소리의 깊이·여유
고음에서 조임 방지
<주의>
공간만 만들고 힘 주면
→ 무겁고 느린 소리
👉 인두 = 깊이와 안정

5️⃣입술·치아 앞쪽 포커스
왜 고음에서 중요?
고음은 위로만 보내면
→ 퍼짐 / 흔들림
그래서 ➡️ 앞으로 모아줘야 함
<위치>
윗입술 안쪽
앞니 뒤
입 밖으로 던지는 느낌 ❌
앞에 걸어둔다 ⭕
<느낌>
소리가 “앞에서 맺힘”
작아 보여도 관통력 큼
<흔한 실수>
턱 밀기
입술 과사용

👉 전방 포커스 = 고음 조준장치


6️⃣후두 하강 공명 (Low Larynx Resonance)
⚠️ “인두 공간”이랑 비슷해 보이지만 의도와 역할이 다름

<핵심>
하품 직전 후두가 살짝 내려간 상태
소리의 두께·무게·안정감 담당
<효과>
고음에서 소리 얇아지는 것 방지
미들~고음에서 “속 빈 느낌” 제거
<주의>
과하면 클래식/뮤지컬 톤
‘내린다’가 아니라 ‘허용한다’ 느낌

👉 인두 공간 = 공간 확보
👉 후두 하강 = 구조 안정화

7️⃣경구개–연구개 경계 공명 (Bridge Resonance)
이건 진짜 미들 보이스 핵심 중의 핵심🔥
위치
단단한 입천장(경구개)과
말랑한 입천장(연구개) 사이 경계
역할
흉성 → 두성 넘어갈 때
끊김 없이 다리 역할
느낌 표현
소리가 “입천장 뒤에서 미세하게 튕김”
울림이 위로 가지만 머리로 날아가진 않음
👉 이게 잘 되면
미들 보이스 = 억지 X / 자연 O

8️⃣안면 마스크 공명 (Mask Resonance)

주의

코로 새면 실패
👉 느낌은 “앞으로 모인다”
👉 소리는 “위로 열린다”
